# Object storage is encrypted with a customer-managed key

| | |
|---|---|
| **ID** | FR-036 |
| **Severity** | medium |
| **STRIDE** | Information disclosure |
| **Category** | Encryption |
| **Platforms** | AWS, Google Cloud |

Requires Action v0.29.0 or later.

## The risk

Object storage is not encrypted with a customer-managed key

## Why it matters

S3 and GCS always encrypt objects with a provider-managed key when you do
not choose otherwise, so this rule is about **who controls the key**, not
whether encryption at rest is on. A customer-managed key (AWS SSE-KMS or
DSSE-KMS with your KMS key; GCS CMEK) lets you rotate, restrict, and revoke
access independently of the cloud account defaults. Cloudflare R2 is not
covered in this version.

## How Fray evaluates it

| Result | Meaning |
|---|---|
| **Open** | Object storage uses a provider-managed key (SSE-S3, the AWS-managed `alias/aws/s3` key, or the GCS Google-managed default). |
| **Mitigated** | Object storage is encrypted with a customer-managed key. |
| **Unverified** | Fray could not tell whether the key is customer-managed (for example an external KMS ARN that cannot be classified). |

## How to fix

Use a customer-managed encryption key on the bucket.

- **AWS** (`aws_s3_bucket` / SSE configuration): set
  `sse_algorithm` to `aws:kms` or `aws:kms:dsse` and
  `kms_master_key_id` to a customer `aws_kms_key` (or alias to one) in the
  plan — not `AES256` and not `alias/aws/s3`.
- **Google Cloud** (`google_storage_bucket`): set
  `encryption.default_kms_key_name` to a Cloud KMS crypto key.

## Waiving it

Add an entry to `.fray/waivers.yml`. Field limits and expiry horizons are in [Waivers](https://github.com/fluong/fray#waivers).
`address` is a Terraform resource address for an element finding, or `<from> -> <to> <data_class>` for a flow finding.

```yaml
version: 1
waivers:
  - id: waiver-1
    rule: FR-036
    address: aws_s3_bucket.uploads
    reason: "Accepted risk; reviewed with the owning team."
    owner: "@security-eng"
    expires: "YYYY-MM-DD"
```
