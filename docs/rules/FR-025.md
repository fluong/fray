# Object storage blocks public access

| | |
|---|---|
| **ID** | FR-025 |
| **Severity** | high |
| **STRIDE** | Information disclosure |
| **Category** | Exposure |
| **Platforms** | AWS, Google Cloud, Cloudflare |

Available since Fray's first public release

## The risk

Public access to the bucket is not blocked

## Why it matters

A bucket that is private today can be opened later by a public grant. A block rejects that grant.

## How Fray evaluates it

| Result | Meaning |
|---|---|
| **Open** | Nothing blocks a later public grant on this bucket. |
| **Mitigated** | Public access is blocked on the bucket. |
| **Unverified** | Fray could not tell whether public access is blocked. |

## How to fix

Block public access on the bucket.

## Waiving it

Add an entry to `.fray/waivers.yml`. Field limits and expiry horizons are in [Waivers](https://github.com/fluong/fray#waivers).
`address` is a Terraform resource address for an element finding, or `<from> -> <to> <data_class>` for a flow finding.

```yaml
version: 1
waivers:
  - id: waiver-1
    rule: FR-025
    address: aws_s3_bucket.assets
    reason: "Accepted risk; reviewed with the owning team."
    owner: "@security-eng"
    expires: "YYYY-MM-DD"
```
