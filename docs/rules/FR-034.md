# Admin ports are not open to the internet

| | |
|---|---|
| **ID** | FR-034 |
| **Severity** | high |
| **STRIDE** | Elevation of privilege |
| **Category** | Exposure |
| **Platforms** | AWS |

Available since 2026-10-13

For full results, use Fray Action v0.21.0 or later.

## The risk

SSH or RDP is reachable from the internet on this instance, Auto Scaling group or EKS node group

## Why it matters

SSH (22) and RDP (3389) open to the internet on a machine with a public address are a direct path to full host control. Fray checks EC2 instances, Auto Scaling groups and EKS managed node groups, including settings from their launch template, launch configuration or remote access settings. Other fleet types are not read yet. Route tables and network ACLs are not checked. An instance without a public IP is not treated as internet-reachable for admin ports even if its security group is open.

## How Fray evaluates it

| Result | Meaning |
|---|---|
| **Open** | The instance, Auto Scaling group or EKS node group has a public IP and its security groups allow SSH or RDP from the internet. |
| **Mitigated** | The instance, Auto Scaling group or EKS node group has no public IP, or its security groups do not allow SSH or RDP from the internet. |
| **Unverified** | Fray could not tell whether the instance, Auto Scaling group or EKS node group has a public IP or what its security groups allow on SSH or RDP. |

## How to fix

Remove the public IP (or Elastic IP), or restrict security group ingress so SSH and RDP are not open to the internet.

- **AWS** (`aws_autoscaling_group`): set `associate_public_ip_address = false` in the launch template's network interface, use private subnets in `vpc_zone_identifier`, and remove internet ingress on 22/3389 from its security groups.
- **AWS** (`aws_eks_node_group`): remove remote_access, or set source_security_group_ids; use private subnets; with a launch template, set associate_public_ip_address = false and keep SSH/RDP closed to the internet.
- **AWS** (`aws_instance`): set `associate_public_ip_address = false` (and remove any Elastic IP), or place the instance in a private subnet.
- **AWS** (`aws_launch_template`): set `associate_public_ip_address = false` in the launch template's network interface, use private subnets in `vpc_zone_identifier`, and remove internet ingress on 22/3389 from its security groups.
- **AWS** (`aws_security_group`): remove ingress that allows TCP 22 or 3389 from the internet; allow only known admin sources.

## Waiving it

Add an entry to `.fray/waivers.yml`. Field limits and expiry horizons are in [Waivers](https://github.com/fluong/fray#waivers).
`address` is a Terraform resource address for an element finding, or `<from> -> <to> <data_class>` for a flow finding.

```yaml
version: 1
waivers:
  - id: waiver-1
    rule: FR-034
    address: aws_instance.app
    reason: "Accepted risk; reviewed with the owning team."
    owner: "@security-eng"
    expires: "YYYY-MM-DD"
```
