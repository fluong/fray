# Traffic from internet-reachable compute to a datastore is encrypted

| | |
|---|---|
| **ID** | FR-035 |
| **Severity** | high |
| **STRIDE** | Information disclosure |
| **Category** | Encryption |
| **Platforms** | AWS, Google Cloud |

For flow rules, Platforms lists the providers whose parsers produce the attributes this rule reads; the rule is evaluated on every matching flow, including flows to other providers (for example a Cloud Run service writing to a Cloudflare R2 bucket).

Requires Action v0.29.0 or later.

## The risk

Internet-reachable process talks to a datastore without TLS on the path or at the datastore

## Why it matters

Compute that the internet can reach often holds credentials and query results
for databases and object storage. If that hop is plaintext and the datastore
does not require TLS, anyone on the path can read the traffic. FR-026 covers
encryption when a flow crosses a trust boundary; this rule is narrower —
internet-reachable compute to a relational database or object store, and it
can pass when either the flow uses TLS or the datastore enforces TLS.
FR-031 checks that a database requires TLS for clients as an element
control; this rule is flow-aware and also covers object storage paths.

## How Fray evaluates it

| Result | Meaning |
|---|---|
| **Open** | Transport is plaintext (and the datastore does not enforce TLS), or the datastore has TLS enforcement off while transport is not TLS. |
| **Mitigated** | The flow uses TLS, or the target datastore enforces TLS (either is enough). |
| **Unverified** | Fray could not tell: transport is unknown or absent and TLS enforcement is also absent. |

## How to fix

Enforce TLS on the database (for example an RDS/Aurora parameter that forces
SSL, or Cloud SQL `ssl_mode` that rejects unencrypted clients), or use TLS
on the connection to the datastore (S3 and similar HTTPS APIs already do).

## Waiving it

Add an entry to `.fray/waivers.yml`. Field limits and expiry horizons are in [Waivers](https://github.com/fluong/fray#waivers).
`address` is a Terraform resource address for an element finding, or `<from> -> <to> <data_class>` for a flow finding.

```yaml
version: 1
waivers:
  - id: waiver-1
    rule: FR-035
    address: aws_ecs_service.app -> aws_db_instance.main unknown
    reason: "Accepted risk; reviewed with the owning team."
    owner: "@security-eng"
    expires: "YYYY-MM-DD"
```
