# Model invocation is scoped to one resource

| | |
|---|---|
| **ID** | FR-004 |
| **Severity** | low |
| **STRIDE** | Elevation of privilege |
| **Category** | Identity |
| **Platforms** | Google Cloud, AWS |

For flow rules, Platforms lists the providers whose parsers produce the attributes this rule reads; the rule is evaluated on every matching flow, including flows to other providers (for example a Cloud Run service writing to a Cloudflare R2 bucket).

Available since Fray's first public release

## The risk

Model access covers every model in the project or account

## Why it matters

A grant wider than one resource lets the caller invoke every model and endpoint in that scope, not only the model this flow uses. On AWS, Fray looks at IAM grants that allow Bedrock invoke (`bedrock:InvokeModel` and related), including policies linked with `aws_iam_role_policy_attachment`, `aws_iam_policy_attachment` (roles only), `aws_iam_role_policy_attachments_exclusive`, and `aws_iam_role_policies_exclusive`. AWS managed policies other than AmazonBedrockFullAccess are not read.

## How Fray evaluates it

| Result | Meaning |
|---|---|
| **Open** | The caller can invoke every model in the project or account. |
| **Mitigated** | The caller can invoke only this model. |
| **Unverified** | Fray could not tell how wide the model grant is. |

## How to fix

Grant the caller access to the single model resource.

- **AWS** (`aws_iam_policy`): Scope the IAM Resource to the specific foundation-model or inference-profile ARN instead of `"*"`.

## Waiving it

Add an entry to `.fray/waivers.yml`. Field limits and expiry horizons are in [Waivers](https://github.com/fluong/fray#waivers).
`address` is a Terraform resource address for an element finding, or `<from> -> <to> <data_class>` for a flow finding.

```yaml
version: 1
waivers:
  - id: waiver-1
    rule: FR-004
    address: aws_ecs_service.app -> signal:iam_service:bedrock unknown
    reason: "Accepted risk; reviewed with the owning team."
    owner: "@security-eng"
    expires: "YYYY-MM-DD"
```
